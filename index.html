Deep Blue Drive Heist

A hands-on AI coding game powered by IBM Bob.

You're at an IBM booth with a laptop. A mysterious thief called The Architect has stolen IBM's Deep Blue Drive source code and is on the run across a series of cities. IBM has a base AI agent ready to track them down — but it needs your help.

Your job: improve the agent using IBM Bob, our AI coding assistant, so it finds the stolen code as fast and accurately as possible. You don't write code yourself — you describe what you want and Bob writes it for you.

Component Role
IBM Bob Players use Bob to code their agent
LangGraph Orchestrates the agentic game engine
Nemotron + NIM All LLM inference for narrator, NPCs, and player agents
