Laptop Setup

Laptops are either macOS, Windows with WSL (Windows Subsystem for Linux), or RHEL-based Linux. These instructions cover all three.

Tip for Windows: Install Windows Terminal from the Microsoft Store before starting. It provides tabs, better copy-paste, and proper Unicode rendering, which makes resetting machines between players much easier than the default console.

Tip for RHEL: Use a terminal that supports standard clipboard shortcuts, such as GNOME Terminal or Ptyxis, so setup and reset commands are easier to copy and reuse during the event.

Tip for all OS Systems: It is recommended (but not necessary) to bring all your installers (Bob, Xcode, etc) on a flash drive or an external drive if possible – this will greatly accelerate the process.

Step 1 — Install WSL

Open PowerShell as Administrator and run:

wsl --install

This installs WSL 2 with Ubuntu. Restart the laptop when prompted, then open Ubuntu from the Start menu to finish initial setup (username + password).

Step 2 — Install uv

Inside the Ubuntu terminal, run:

curl -LsSf https://astral.sh/uv/install.sh | sh

Step 3 — Install Node.js

Node.js 24+ is required to run the MCP investigation tool servers. In the terminal, run:

curl -fsSL https://fnm.vercel.app/install | bash
source ~/.bashrc
fnm install 24
node --version

You can find other ways to download Node here.

Step 4 — Install IBM Bob

Download and install IBM Bob. You will need a Bob account with sufficient Bob coins (approximately 200) to log in – there will likely be accounts set up for you in advance. If you do not have access, please contact the DevRel team.

Step 5 — Bootstrap booth setup

Open IBM Bob. After logging into your Bob account, in the terminal, run:

curl -fsSL https://ibm.biz/bobgame-setup | sh

You will be prompted for credentials:

Tenant: tenant-id          # your tenant id
Machine number: 25         # any number 0–99, unique per machine
Booth password: tenant-password
Pin data prefix to a fixed date? (multi-day single competition; blank = daily) [YYYY-MM-DD]: YYYY-MM-DD # date of the event to set prefix

Your unique credentials will be given to you. Machine numbers must be unique per machine. If problems arise with the repository, delete it and run this step again.

Important: Never copy .env from one laptop to another — MACHINE_ID must be unique per machine.

After it finishes, open the Explorer by clicking the first icon on the left bar, resembling a stack of papers. Choose "Open Folder", look for bobgame-experience-booth in the directory, and open it. Your IBM Bob IDE should automatically open the game repository, which will be listed on the left-hand side in the explorer tab.

Step 6 — Set up the player-ready screen

Start the server in the terminal:

uv run launch.py

Once the dashboard is running at http://localhost:8000:

  1. In Bob, open PLAYER_README.md and src/game_engine/agents/player_agent.py — keep PLAYER_README.md as the active tab.
  2. Open Microsoft Edge to http://localhost:8000 and move the window to the front of the screen.
