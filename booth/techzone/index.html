TechZone Configuration

Instructions for setting up Deep Blue Drive Heist via TechZone for workshops can be found here.

Before You Get Started...

  • This process will take at least 20-30 minutes of set up.
  • TechZone virtual PCs can sometimes experience lag. This is not an issue with IBM Bob or the Deep Blue Drive Heist game.
  • When working with RedHat, be aware that commands to copy and paste differ from general Mac and Window set ups:
    • Copy: Ctrl + Shift + C
    • Paste: Ctrl + Shift + V
  • You can additionally offer a guide for players found here.
  • You will encounter 4 different login screens:
    • Logging into TechZone and IBM Bob: use your IBM ID
    • Logging into the virtual machine: use the provided TechZone credentials
    • Logging into the Deep Blue Drive Heist game: create your own username

The Process

Part One: Opening TechZone and the Virtual Machine

Log into techzone.ibm.com with your IBM ID. Navigate to the My TechZone tab on the top left corner, and click My requests.

In the My requests page, you will see your assigned IBM Bob instance for running the workshop. Click on Open this reservation.

You will now see the Environments page. Click on the OCP-C RHEL Bob IDE Environment. The tab will collapse to show you more information about the environment.

Click on the URL on the right hand side of the screen to access the virtual machine.

You will be taken to the Virtual Machines page. Click Console to open your virtual machine.

You will be prompted to connect with RDP before entering your virtual machine. Click Connect with RDP to continue.

Part Two: Inside the Virtual Machine

You are now successfully inside your virtual machine.

You will be prompted to enter a password. Click Show Credentials on the top left.

Click on the keyboard icon on the right side of the password credential field. This will automatically copy and paste your password into the login field. Click Enter on your keyboard. This is where you will use the provided TechZone credentials.

If you are taken directly to IBM Bob and the game, and your screen looks similarly to this image below with the game engine open and set up, please proceed to Part Three.

If your screen looks like the image below, you are in the home screen. Click on Activities in the top left corner.

Click on the Show Applications icon.

Click on IBM Bob.

Once IBM Bob application opens, it will ask you for imports. Click Skip for now.

You may be prompted to "Choose a password for new keyring". Ignore this by pressing enter on your keyboard through both pop ups, then click continue when prompted.

You may be prompted to continue old Bob chats. Click Skip migration.

Part Three: Logging into Bob

If you have the IBM Bob application open (with or without the game window) and your Bob window has a blue "Login to Bob" button (as referenced in the image below), you will need to log into Bob with your IBM ID or with your Bob account.

Once you finish log in, you should be taken back to the IBM Bob application.

If you see both the set up game and the IBM Bob application ready for use (exactly like this image below)...

  • If you are setting up as a player: You may skip the rest of these instructions and learn how to play Deep Blue Drive Heist with this player guide.
  • If you are setting up as a staff member: You may skip the rest of these instructions and use the staff references and/or the staff script to continue to support player experience.

If you do not have the game open (you do not see the agent login screen and/or the terminal panel is not running the game)...

  • If you are setting up as a player: Please contact staff to finish set up.
  • If you are setting up as a staff member: Please proceed to Part Four.
Part Four: Setting Up the Game

Open a new terminal.

Type in these commands in the terminal.

curl -fsSL https://ibm.biz/bobgame-setup | sh

You will then be prompted for credentials:

Tenant: tenant-id          # your tenant id
Machine number: 25         # any number 0–99, unique per machine
Booth password: tenant-password
Pin data prefix to a fixed date? (multi-day single competition; blank = daily) [YYYY-MM-DD]: YYYY-MM-DD # date of the event to set prefix

Within your terminal, navigate into the bobgame-experience-booth folder:

cd bobgame-experience-booth

Now run the server:

uv run launch.py

This will start the game engine.

Within the Bob application, open the bobgame-experience-booth folder from your directory.

Navigate to Home and click on bobgame-experience-booth.

Once the repository is opened, open the player_agent.py file to have on display for players.

Open PLAYER_README.md, right click on it, and preview it.

Now, open up a browser window within the virtual machine.

Type in localhost:8000, and click Enter on your keyboard.

The local server should show up, where your game engine will be running. This is where you will create your own username to login to the game.

Congratulations, you have successfully set up the Deep Blue Drive Heist!
