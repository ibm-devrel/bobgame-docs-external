Pre-work

Complete these steps before the workshop so your laptop is ready to play.

Using a workshop-provided machine?

If your laptop was set up for you (WSL and IBM Bob already installed), skip step 1 in the laptop setup guide. You may also skip step 4, but make sure to log in to IBM Bob.

1. Set up your laptop

Follow the Laptop Setup guide for your OS (Windows with WSL, macOS, or RHEL).

Laptop Setup →

2. Windows only: connect IBM Bob to WSL

On Windows, the game is installed and run inside WSL, not in PowerShell. Follow these steps in place of Step 5 in the laptop setup guide, then continue with Step 6.

Open FedoraLinux-44

Open the Start menu, search for FedoraLinux-44, and open it. This is your WSL terminal. Use it for the commands in Steps 2 and 3 of the laptop setup guide as well, wherever the guide says Ubuntu.

The terminal opens in your home folder, /home/student. From there, run the booth setup:

curl -fsSL https://ibm.biz/bobgame-setup | sh

Enter your credentials when prompted, as described in Step 5. The game repository is placed in /home/student.

Install the WSL extension

Open IBM Bob and log into your Bob account. Open the Extensions view by clicking the icon on the left bar resembling four squares. Search for "Open Remote - WSL", and install the extension by jeanp413.

Connect to WSL

Use Ctrl+Shift+P to open the command palette, type "WSL", and choose "Connect to WSL". A new IBM Bob window opens, connected to FedoraLinux-44. Use this new window from here on.

Open the game folder

In the new window, open the Explorer by clicking the first icon on the left bar, resembling a stack of papers. Choose "Open Folder". It opens in /home/student; look for bobgame-experience-booth in the directory, and open it. The terminal in this window also runs inside WSL, so you can continue with Step 6 of the laptop setup guide from here.

3. Check you're ready

  • IBM Bob opens and you can sign in
  • On Windows, IBM Bob is connected to WSL and the game folder is open from /home/student
  • The game repo is cloned and the game starts
  • You've skimmed the player guide, so you briefly know how the game is played
