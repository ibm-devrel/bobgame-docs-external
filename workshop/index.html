Deep Blue Heist Workshop

What You'll Learn

In this hands-on workshop you'll play Deep Blue Drive Heist, a text adventure where an AI agent chases "The Architect" across a map of cities, and use IBM Bob to make that agent smarter. Across four modules you'll build up a set of concepts that help you prompt Bob more strategically: how agents are put together, why they struggle with hidden information, and how to experiment on them the way you would a production system.

Workshop Flow

  1. Pre-work: get your laptop set up before the session starts.
  2. Module 0: What is the Deep Blue Heist?: How IBM Bob works, and the real basics of solving problems with an AI coding assistant.
  3. Module 1: The World of Agents: What an agent is, how this one is built (LangGraph, hooks, MCP tools, memory), and how to steer it with Bob.
  4. Module 2: Agents and Non-determinism: Agent cognition vs. human cognition: giving the agent the map it can't see, and helping it revise its beliefs.
  5. Module 3: An Experimental Framework for Production Agents: Test vs. prod, verification loops, and comparing agent runs systematically, all the way to loop engineering.
Time Estimate

The workshop (the "lab") runs 90 min. Each module opens with a short scene-setting + concept talk, then you play at least one round of the game after prompting Bob as the module guide describes.

The Problem

Deep Blue Drive Heist was built so players can experience the world of agents first-hand, and learn to use an AI coding assistant like IBM Bob to improve one.

The catch: the game is deceptively hard! For humans, solving this puzzle would be extremely fast and easy. For AI agents, it's much more difficult. The question we explore today is: what makes it so hard? And what does that mean for the agents you build in production?

Over about a dozen events, only about 1 in 10 players were able to build agents that could solve the 26-city version of the game.

The agent pops up in a new city with nothing but its notebook and whatever the narrator tells it. It can't see the map, doesn't know how long it's been, and believes everything it has written down, even the parts it hallucinated.

So how do you, with Bob's help, give an agent what it needs to reason its way to the drive?

Audience: Beginner-to-intermediate: experienced developers who know less about AI.
